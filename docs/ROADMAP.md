# Roadmap

## v0.2 — Proof room
- horizontal voice-resolution flagship
- deterministic action policy
- simulator + Vapi-ready live path
- transcript + trace
- ROI ledger + monthly projection
- evidence provenance
- 12-scenario reliability matrix
- 11 executable policy/economic contract tests
- Build OS / case study / demo script

## v0.3 — Provider truth
- run provider-verified Vapi call set
- ingest provider duration/cost/transcript evidence
- implement intent-version IDs
- stale-result rejection regression test
- durable authenticated event store

## v0.4 — Multi-provider control plane
- second live voice adapter (Retell or LiveKit)
- normalized provider event schema
- blueprint versioning
- automated replay/eval worker
- configurable approval policies

## v0.5 — Customer pilot kit
- baseline import
- pilot cohort comparison
- customer-specific workflow mapper
- deployment readiness report
- exportable ROI/evidence brief
- multi-tenant auth, RBAC and audit log

## North star
A deployment team should be able to bring a workflow and answer, with evidence:
**Should this agent launch, what is it allowed to do, what did it actually do, what did it cost, what value did it create, and what did we learn that improves the next deployment?**
